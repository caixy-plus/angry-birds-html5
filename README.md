# 🐦 Angry Birds HTML5 (纯原生 HTML5 + Canvas + JS)

一个零外部依赖、使用纯 HTML5 Canvas 2D 与原生 JavaScript 编写的《愤怒的小鸟》完整版网页游戏。内置自研 2D 刚体/旋转矩形（OBB 分离轴定理 SAT）物理引擎、Web Audio API 合成器音效、多关卡系统以及 AI 自动一鸟三星通关演示。

## ✨ 功能特性

- **纯原生零依赖**：仅需浏览器打开 `index.html` 即可畅玩，无需任何构建工具或第三方库。
- **真实 2D 刚体坍塌物理（OBB SAT）**：
  - 基于旋转矩形四顶点与分离轴定理（SAT）的精确碰撞检测。
  - 支持悬臂失衡倾覆力矩（Cantilever Torque）、多米诺骨牌式立柱倾倒、建材碾压伤害与裂缝受损视觉效果。
- **四种经典小鸟与飞行特技**（飞行途中按 `Space` 空格键、点击画布或点击顶部 **⚡ 特技** 按钮触发）：
  - 🔴 **怒红鸟 (`red`)**：怒火冲击波，震飞并破坏周围建材与绿猪。
  - 🟡 **飞镖黄 (`yellow`)**：直线极速冲刺，对木头与石块造成高额穿透伤害。
  - 🔵 **蓝弟弟 (`blue`)**：空中三重分身，大范围打击玻璃/冰块结构。
  - ⚫ **炸弹黑 (`black`)**：高爆震荡波，大范围摧毁掩体与绿猪。
- **三种可破坏建材**：玻璃（`glass`）、木头（`wood`）、巨石（`stone`），具备不同密度、生命值、弹性与得分。
- **🤖 AI 一鸟通关演示**：点击顶部 **「🤖 演示一鸟通关」** 按钮（或访问 `index.html?demo=1`），即可观看 AI 自动拉弓、瞄准、发射并触发红鸟特技实现第一关一鸟三星满贯。
- **Web Audio 合成音效**：内置发射、碰撞、绿猪消灭、爆炸与通关和弦音效，支持一键静音切换。

## 🚀 快速开始

### 直接运行
在浏览器中直接打开 `index.html`：
```bash
open index.html
```
或者开启 AI 演示模式打开：
```bash
open "index.html?demo=1"
```

### 运行自动化测试
项目包含 13 项针对物理引擎、弹弓限幅、四种小鸟特技、坍塌防悬空与木柱砸猪的单元测试：
```bash
node test.js
```

## 📁 目录结构

- `index.html` — 游戏主界面、顶部 HUD 状态栏与关卡结算 `<dialog>` 模态框
- `style.css` — 响应式 16:9 游戏视口与毛玻璃 HUD 样式
- `game.js` — 2D 物理引擎、小鸟/绿猪/建材渲染与 Web Audio 音效合成器
- `test.js` — Node.js 自动化单元测试套件
